# Utils

Independent utility projects. Each tool keeps its code, dependencies,
documentation, and generated-file exclusions in its own directory.

## Tools

- [ChatGPT Continue Timer](chatgpt-continue-timer/README.md) — a double-click
  Windows app that sends `continue` to an open ChatGPT or Codex conversation after a delay.
- [Disk Usage Report](disk-usage-report/README.md) — a standalone Windows app
  with configurable parallel scans, live worker activity, and interactive trees.
